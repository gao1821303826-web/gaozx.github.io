Educational Knowledge Graph & GraphRAG

Knowledge Graph · GraphRAG · Neo4j · LLM

This project explored the use of knowledge graphs and graph-based retrieval to organize and retrieve educational knowledge for large language model applications.

An educational knowledge graph was constructed to represent relationships among educational concepts and knowledge elements. Neo4j was deployed in a Docker environment as the graph database, providing the infrastructure for storing and querying the structured knowledge.

GraphRAG was then introduced as a retrieval approach that connects graph-structured knowledge with large language models. The project provided practical experience in combining structured knowledge representation with LLM-based information retrieval.

Implementation

  • Deployed Neo4j using Docker as the underlying graph database.
  • Constructed an educational knowledge graph to represent relationships among educational knowledge elements.
  • Explored GraphRAG for graph-based knowledge retrieval.
  • Integrated graph-structured knowledge with large language model applications.

Technologies

Knowledge Graph · GraphRAG · Neo4j · Docker · Large Language Models
